# Imágenes del hero (Buxxep)

Las rutas de las imágenes **no son inventadas**: corresponden a estos posts de Instagram. Descarga la imagen de cada enlace y guárdala aquí con el nombre indicado.

| Archivo   | Post de Instagram |
|-----------|-------------------|
| `1.jpg`   | https://www.instagram.com/buxxep/p/DBURvQ9vqA-/ |
| `2.jpg`   | https://www.instagram.com/buxxep/p/DBURRqrPXqt/ |
| `3.jpg`   | https://www.instagram.com/buxxep/p/DBURFxEP3Ti/ |
| `4.jpg`   | https://www.instagram.com/buxxep/p/CxGm1UVP5sC/ |
| `5.jpg`   | https://www.instagram.com/buxxep/p/CxGmx8_vwrf/ |

1. Abre cada enlace en Instagram.
2. Descarga la imagen del post (guardar imagen / copiar).
3. Guarda en esta carpeta como `1.jpg`, `2.jpg`, … `5.jpg`.

La landing usa estas rutas en `config/landing-images.ts`. Instagram no permite usar las URLs de las fotos directamente como `src`, por eso se sirven desde esta carpeta.
