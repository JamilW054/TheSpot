# Modelos 3D

El editor usa por defecto la **camiseta en GLTF** en `/models/tshirt/scene.gltf` (permite editar diseño, texturas y guardar todo correctamente).

Para que el modelo de camiseta cargue bien, en `tshirt/` deben estar:
- `scene.gltf`
- `scene.bin`
- carpeta `textures/` con las imágenes del modelo

Otras prendas (opcionales): `male_tshirt.glb`, `hoodie.glb`, etc. en esta carpeta.
