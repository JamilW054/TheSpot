# Modelo camiseta (GLTF)

Este modelo se usa en el editor 3D. Para que cargue correctamente necesitas:

- `scene.gltf` (incluido)
- `scene.bin` (geometría) — debe estar en esta misma carpeta
- `textures/` — carpeta con las imágenes referenciadas en el GLTF (Material1718_baseColor.jpeg, etc.)

Si descargaste el modelo desde Sketchfab, copia también `scene.bin` y la carpeta `textures/` aquí.
